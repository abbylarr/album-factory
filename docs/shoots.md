# Съёмки в заказе

Этот документ описывает текущую реализацию съёмок. Целевая модель участников, доступа, вариантов альбома и согласования — [domain-model.md](domain-model.md); будущие требования не следует считать уже реализованными.

В интерфейсе V2 заказ содержит любое число портретных и общих съёмок. Первая съёмка раскрывается автоматически, остальные доступны в компактном списке над фотографиями. Переключение сбрасывает выделение и фильтр; свёрнутые съёмки не выводят свои фотографии в DOM.

«Добавить съёмку» задаёт тип и название. Загрузка внутри раскрытого раздела относится к этой съёмке; общий диалог загрузки позволяет выбрать существующую или создать новую. Назначение фиксируется на всю текущую загрузку, даже если фотограф переключит раздел. Общие фото доступны для просмотра, выбора обложки и удаления. Их автоматическая сортировка и выбор клиентом — отдельный следующий этап.

## Хранение и совместимость

- `shoots`: id, order_id, kind (`portrait` / `general`), title, created_at.
- `photos.shoot_id`: ссылка на съёмку. При обновлении существующие фотографии получают портретную съёмку «Портреты» своего заказа, без изменения персон и результатов анализа.
- `POST /api/orders/{order_id}/shoots`: создать съёмку.
- `GET /api/orders/{order_id}`: массив shoots, shoot_id и shoot_type на фотографиях.
- `POST /api/orders/{order_id}/photos?shoot_id=...&filename=...`: загрузить в съёмку данного заказа. Старый интерфейс без shoot_id загружает в первую портретную съёмку.
- Защита от дублей остаётся на уровне заказа: повтор в той же съёмке пропускается; файл из другой съёмки возвращает понятную ошибку, а не исчезает из текущей загрузки молча.
- Лимит 3000 фотографий остаётся общим для заказа. Переименование, удаление съёмки и перенос между съёмками пока не добавлены.

## Обработка

Портретная съёмка использует V3. Пакеты очереди и подсказки по номерам ограничены съёмкой; сходство лиц может узнавать уже существующих персон заказа. Общая съёмка сохраняет оригиналы и превью без распознавания лиц, не создаёт персон и не попадает в счётчик проверки совпадений. Повтор обработки из V2 ограничивается раскрытой съёмкой.

Клиентский кабинет пока сохраняет прежний сценарий выбора портретов. Для общих съёмок потребуется отдельное правило выбора и собственная стратегия обработки, без запуска портретного правила соседних кадров.
