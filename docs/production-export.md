# Производственный комплект

Обновлено 30 сентября 2026. Закрыты Б8 и Н1 из [мастер-аудита](service-master-audit-2026-09-30.md): после разрешения производства макет защищён от изменений, а «Заказ класса» выдаёт настоящие файлы вместо PDF-заглушек.

## Работа фотографа

1. Соберите макет, проверьте его и опубликуйте для класса. Опубликованная редакция содержит именно то, что класс согласует.
2. Заказчик с кодом управления распределяет тираж, выбирает получение и согласует сводку. Количество подарков задаёт фотограф.
3. Нажмите «Отправить в печать». Если подарочный получатель `gift` не имеет отдельного варианта `teacher_variant`, выберите опубликованный альбом, который нужно изготовить для учителя. Без выбора отправка блокируется. Сервис не подменяет подарок первым ученическим альбомом автоматически. Если подарок уже распределён по ученическим строкам, используется вариант соответствующего ученика.
4. Во вкладке «Анкеты», блок «Решения класса», скачайте PDF или ZIP с JPEG по получателю либо «Скачать весь комплект». Полный ZIP содержит PDF, JPEG-архивы и manifest.json с распределением, редакцией и параметрами вывода.

Каждая строка получателя с ненулевым количеством имеет своё уникальное имя файла; одинаковые имена людей не перезаписывают друг друга. Файл альбома создаётся один раз, а число платных и подарочных экземпляров указывается в ведомости. Несколько получателей могут явно использовать один вариант. Для ученика требуется его собственный вариант в публикации: отсутствие альбома блокирует производство с 409.

## Фиксация и защита

При публикации сохраняются документ, исходный снимок данных генерации и комплектация. При разрешении производства фиксируются тираж, получение, сопоставление получателей с вариантами, документ публикации, используемые фотографии и байты шрифтов. Фотографии копируются в `data/production/<order>/<hash>/`; изменение или пропажа рабочего оригинала не подменяет готовый комплект. Разрешённый источник хранится в `production_layouts`, исходник публикации — в `publication_sources`; таблицы создаются при запуске.

Печать, доставка, архив и само наличие разрешения производства закрывают все маршруты изменения: генерацию, смену мастер-макета через генерацию, операции над элементами/разворотами, замену overrides, прежние маршруты добавления/шаблона/удаления разворота, отметки проверки и публикацию. Ответ 409 не изменяет макет. Возврат этапа назад не отменяет фиксацию. Сценарий позднего исправления отдельной версией пока не реализован.

Редактор показывает «Только просмотр», отключает изменения и использует документ и фотографии производства. Вкладка «Макет» также запрещает обновление. PDF/JPEG редактора для таких заказов берутся из разрешённого источника, а не из черновика. Вариант без экземпляров в разрешённом тираже не выдаётся как печатный файл (404).

Комплект строится во временной папке, затем публикуется готовым. Сборки одного заказа сериализованы файловой блокировкой. Кеш проверяется по версии формата, хешу разрешённого источника и контрольным суммам файлов. Старые заглушки, повреждённые и пропавшие файлы пересоздаются. Перед повторной сборкой проверяется целостность сохранённых фотографий. Удаление целого заказа удаляет также производственные ресурсы и экспорт.

## Старые заказы

Исторические публикации без сохранённого источника дополняются только если рабочий документ полностью совпадает с опубликованным. Если он отличается, выпуск блокируется с объяснением: автоматически восстановить прежние фотографии/шрифты по одному номеру редакции невозможно. Требуется восстановление исходника публикации, а не экспорт нового черновика под прежним согласованием.

Для ранее разрешённого заказа без выбранного подарочного варианта может потребоваться повторное разрешение с `gift_owner`. Уже созданный производственный снимок повторным разрешением не меняется. Эти ограничения не заменяются молчаливым выбором другого альбома.

## API

- `POST /api/orders/{id}/production`: `{responsibility: boolean, gift_owner?: string}`. `gift_owner` — owner из вариантов опубликованного документа; нужен для отдельной строки подарка без teacher_variant.
- `GET /api/orders/{id}/export`: ведомость, редакция, `production_hash`, `layout_hash`, PDF/JPEG-имена, тираж и контрольные суммы. Технические поля предназначены для проверки целостности.
- `GET /api/orders/{id}/export/download`: полный ZIP.
- `GET /api/orders/{id}/export/files/{filename}`: только PDF/JPEG-имена из ведомости; произвольные файлы не выдаются.
- `GET /api/orders/{id}/production/photos/{photo_id}`: сохранённая фотография для просмотра зафиксированного макета.

Все скачивания проверяют принадлежность заказа студии. Клиентская ссылка класса не предоставляет доступ к производственному комплекту.

## Проверка и границы

`tests/test_production_export.py` содержит пять регрессий: реальный путь загрузки/анкет/согласования/производства; содержимое PDF, JPEG и ZIP; запрет всех правок и переключения этапа; экспорт опубликованной редакции при более новом черновике; обязательность подарочного варианта и наличие альбомов всех получателей; восстановление повреждённого кеша и удаление ресурсов заказа. `tests/test_production_ui.js` проверяет режим просмотра вкладки «Макет».

Контрольный проход использует вымышленные данные и три геометрические карточки. Загрузка, ручная группировка, анкеты, публикация, согласование и производство проходят через HTTP API приложения; заменён только результат распознавания лиц на карточках. В браузере проверены выбор подарка, запрет отправки без выбора, перевод в печать, ссылки и скачивание ZIP, отключённые действия редактора и вкладки «Макет». Все страницы контрольного PDF визуально просмотрены после рендеринга Poppler. Материалы: `output/production-check-2026-09-30/`.

PDF содержит настоящие изображения, текст и встроенные шрифты. JPEG повторяет геометрию PDF, имеет sRGB-профиль и 300 dpi; для книжного режима используются отдельные страницы без непечатаемых наружных половин. Это **RGB-комплект без заявления о PDF/X, CMYK, согласованном ICC output intent или вылетах**. Формат, цветовой профиль и вылеты необходимо согласовать с конкретной типографией; физическая печать не проверялась. Большой тираж, массовые параллельные скачивания и тысячи вариантов не испытывались в этом контрольном проходе.
